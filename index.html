Como usar

  1. Abra o SGP da InfoAssis e faça login normalmente.
  2. Clique no favorito SGP Dashboard · Gráfico com rótulos. O painel abre em uma aba separada.
  3. Passe o mouse sobre qualquer fatia para ver o responsável e a quantidade de OS. Os números também ficam escritos nas fatias.
  4. Clique numa fatia para abrir a lista compacta daquele responsável. O painel continua atualizando a cada 60 segundos.

O que há nesta versão

  • Nome e quantidade no tooltip ao passar o mouse.
  • Quantidade de OS escrita em cada fatia.
  • Atualização automática e botão de atualização manual.
  • Listas compactas com OS, Cadastro, Agendamento, Bairro e links EDITAR.
  • Sem extensão, servidor ou envio dos dados para terceiros.

O favorito precisa ser executado a partir de uma página do SGP logada. A aba do painel continua funcionando enquanto a sessão estiver válida.
